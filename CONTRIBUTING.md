# Contributing

Use Node 24 and `npm ci`. Work on a short-lived branch and open a pull request. Run typecheck, lint, tests and the production build before requesting review. Add regression coverage when changing data validation, migrations, authentication or calculations.

Use synthetic examples. Never submit databases, receipts, VINs from household records, screenshots with personal data, environment files, setup links, tokens or private deployment details. Keep published migrations unchanged. Household account creation stays server-only; public registration and multi-household hosting are outside the current design.
