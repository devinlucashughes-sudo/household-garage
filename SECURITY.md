# Security

Each installation serves one trusted household. All signed-in members share access to its records. Run behind HTTPS in production, keep the host and dependencies updated, and restrict server administration. Protect the database and all backups as secrets. Creating a setup link grants the recipient the ability to register a passkey for that account.

Please report suspected vulnerabilities through GitHub's private vulnerability reporting feature when available. If it is unavailable, open an issue asking for a private reporting channel without disclosing exploit details, private records or credentials. This personal project has no guaranteed response schedule. Public source availability is not a security certification.
